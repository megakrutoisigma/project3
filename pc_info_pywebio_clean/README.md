# Информация о ПК

**Индивидуальный проект**: сайт для просмотра характеристик и мониторинга компьютера. Python + **PyWebIO** + HTML/CSS. Сбор данных через **psutil**, `platform`, `sys`, `os`.

## Быстрый запуск (Windows 10/11)

**Самый простой способ:** дважды нажмите `start.bat`. Он использует отдельное
окружение `.venv`, при первом запуске устанавливает зависимости и открывает сайт
в браузере. При первой установке нужен интернет; оформление сайта загружается локально.
Проверено на Python **3.14**. Для остановки нажмите Ctrl+C в окне сервера.
Не запускайте второй экземпляр, пока первый занимает порт 8080.

Для ручного запуска подготовленного окружения:

```powershell
.\.venv\Scripts\python.exe app.py
```

Альтернативная ручная установка:

1. Установите Python. Рекомендуется Python **3.12** или **3.13** (на более новых версиях совместимость PyWebIO может потребовать проверки).
2. Откройте терминал из папки проекта.
3. Установите библиотеки:

   ```powershell
   py -m pip install -r requirements.txt
   ```

4. Запустите сайт:

   ```powershell
   py app.py
   ```

5. Откройте **http://127.0.0.1:8080** в браузере.

Чтобы остановить приложение, нажмите **Ctrl+C** в терминале.

## Возможности

- Личный веб-сайт мониторинга с адаптивным HTML/CSS из `assets/site.html`.
- Загрузка CPU, RAM, занятого места, число процессов, время работы ОС.
- Живое обновление показателей каждые 3 секунды и временная история в памяти за последние 10 минут (новый замер каждые 5 секунд).
- Графики CPU/RAM в формате SVG, генерируются Python, работают без интернета и JavaScript-библиотек.
- Информация о системе, процессоре, памяти, сетевых адаптерах, дисках, батарее и разрешении основного экрана (Windows).
- NVIDIA GPU через `nvidia-smi` (температура, нагрузка, VRAM); имя других GPU на Windows, если доступно через PowerShell.
- Топ процессов, поиск и сортировка, завершение **выбранного PID только с подтверждением**.
- Просмотр автозагрузки в режиме только чтения.
- Размер папки и поиск 10 крупных файлов (лимит обхода 12 000 файлов).
- Диагностика DNS, TCP-подключения и ping; короткий CPU-бенчмарк.
- Простая автоматическая диагностика перегрузки и уведомления через журнал.
- Экспорт отчётов в TXT и HTML, отдельная вкладка логов.
- Сборка сервера сайта в EXE (Windows) через `build_exe.bat`.

## Структура проекта

```text
app.py                # Сайт на PyWebIO, вкладки, обработчики и обновление
pc_stats.py           # psutil, platform, sys, os: получение данных ПК
features.py           # Диагностика, сеть, тест CPU и действия с процессом
metrics_history.py    # Последние 120 замеров в оперативной памяти
reports.py            # TXT/HTML отчёты
logger_setup.py       # Logger + ротация логов
assets/site.html      # HTML и CSS интерфейса
requirements.txt      # Зависимости
build_exe.bat         # Сборка приложения для Windows
```

**Базы данных нет.** Замеры хранятся только в оперативной памяти и исчезают при остановке приложения. На диск записывается только журнал событий `data/logs/app.log` (у EXE — `%LOCALAPPDATA%\PCInfoWeb\logs\app.log`). Журнал не должен попадать в публичный GitHub-репозиторий.

## Доступ с другого устройства в локальной сети

Для доступа в локальной сети сначала **обязательно задайте пароль**. В PowerShell:

```powershell
$env:APP_PASSWORD="придумайте-длинный-случайный-пароль"
$env:HOST="0.0.0.0"
py app.py
```

На телефоне в той же сети откройте `http://IP_КОМПЬЮТЕРА:8080`.

**Предупреждение:** HTTP в локальной сети не шифрует пароль и данные. Для использования вне доверенной домашней сети необходим HTTPS через защищённый прокси/VPN и дополнительные ограничения доступа. Не пробрасывайте порт 8080 в интернет. Не запускайте программу от администратора без необходимости.


## EXE

На Windows запустите `build_exe.bat`. Полученный `dist/PC-Info-Web.exe` запускает **локальный веб-сервер**: браузер всё равно нужен. HTML и CSS упакованы в EXE. Сборка не тестировалась на всех версиях Python.

## Ограничения

- Программа отображает **состояние ПК, где запущен Python**, а не характеристики телефона с открытым сайтом.
- Температуры зависят от датчиков, драйверов, ОС. Нельзя гарантировать их наличие.
- Процессам и дискам иногда нельзя получить доступ без дополнительных прав; ошибки не должны останавливать весь сайт.
- Некоторые функции (Windows-автозагрузка, определение монитора, имя не-NVIDIA GPU) зависят от ОС.
- Проверка диагностики основана на простых правилах и не заменяет SMART-диагностику оборудования.
- В PyWebIO визуальные элементы отправляются Python-сервером. Это **не отдельный статический сайт**, `assets/site.html` отвечает за оформление.
